# Proyecto M.A.D.I.

**M.A.D.I. — Módulo Autónomo de Datos e Inteligencia**

Proyecto independiente de inteligencia y asistencia, diseñado desde el inicio para poder integrarse posteriormente con **SicherERP**.

## Versión

`v0.1` — Fundación del proyecto.

## Estado

🟢 Repositorio inicializado. La versión 0.1 se construirá de forma incremental, verificable y preservando cada estado funcional.

## Principios de desarrollo

- Arquitectura modular y extensible.
- Separación clara entre núcleo, interfaces e infraestructura.
- Proveedores de IA desacoplados del núcleo.
- Configuración mediante variables de entorno; nunca almacenar secretos en el repositorio.
- Cambios pequeños, comprobables y con commits funcionales.
- Compatibilidad futura con SicherERP sin acoplar M.A.D.I. a SicherERP en v0.1.

## Próximo objetivo

Construir el núcleo mínimo ejecutable de M.A.D.I. y establecer la base técnica sobre la que evolucionarán sus capacidades de inteligencia, memoria, herramientas e integración.
